# feminostrategy-ai-index

Books and chapter index for connecting LLMs (Claude, ChatGPT, Cursor).

Пять книг Антона Сорвачёва в txt и готовый индекс к ним для работы с нейросетями.
Книги выложены с согласия автора.

## Структура

```
books/
  feminostrategy-1/     Феминостратегия
  feminostrategy-2/     Феминостратегия 2.0
  luani/                Путь Луани
  matriarchal-code/     Матриархальный код
  stai-roi/             О стае, рое и феминостратегии
```

В каждой папке книги:

| Файл | Что это |
|---|---|
| `book.txt` | полный текст книги, одна строка файла = одна строка ссылки в индексе |
| `toc.md` | оглавление: размер, оценка токенов, заголовки с номерами строк, разбивка на куски по ~40k токенов |
| `cards/part-N.md` | карточки глав: по каждой главе диапазон строк, о чём, утверждения автора с номером строки |

## Как подключать нейросеть

1. Дать модели `toc.md` нужной книги: она увидит карту книги и строки глав.
2. Для вопроса по содержанию дать `cards/part-N.md`: это выписки, в 5–10 раз короче книги.
3. Для проверки цитаты открыть `book.txt` по номеру строки из карточки (например, `sed -n '461,465p' book.txt`).
4. Книгу целиком давать модели только если нужен дословный текст: самая большая (Матриархальный код) ≈ 420 тыс. токенов.

Прямые ссылки на файлы для моделей с доступом в интернет:
`https://raw.githubusercontent.com/Qordis/feminostrategy-ai-index/main/books/<папка>/<файл>`

## Как собран индекс

- `toc.md` построен скриптом без нейросети: поиск заголовков по словам «глава / часть / раздел», нумерации и капсу, подсчёт токенов по 2,6 символа на токен, нарезка на куски.
- `cards/` написаны моделью Claude Opus: каждая часть книги (до 125 тыс. токенов) читалась отдельным агентом, задание — на каждую главу выписать утверждения автора с номером строки, интерпретации пометить как интерпретации, от себя ничего не добавлять.
- Утверждение из карточки проверяется поиском по `book.txt` по указанной строке.
